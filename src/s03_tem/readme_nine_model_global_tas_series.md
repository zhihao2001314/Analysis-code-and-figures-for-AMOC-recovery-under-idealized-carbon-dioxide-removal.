## 数据与维度

两阶段分别读取 `F:/sea/cmip6tasad/` 和 `F:/sea/cmip6tas/` 的标准Amon tas月资料。
所有模式实际维度均为 `tas(time,lat,lon)`，单位K，经纬度为一维；标准2m气温包含全球陆地与海洋。
CAS也使用新补齐的标准月资料，两阶段均不使用旧年度最低模式层代理。每模式一个成员，清单和真实维度、日历、文件大小、修改时间保存在source_inventory.csv。

## 计算与显示

原生大气网格上以球面纬度边界的sin差及等间隔经度加权全球平均；CNRM采用与其高斯纬度逐点核对的Gauss–Legendre面积权重，不做空间插值。月均按CF time bounds实际月时长加权为年均，每年必须有完整且唯一的12个月。

每个模式减去自身实验年1–10的未平滑年均值，单位°C。默认原始强迫资料，无piControl漂移订正。绘图显示跨越140/141年的连续11年居中平均，整个实验两端至少6年。不将CO2升降两段分别平滑，不强制端点一致，也不作人为平移。原始月值、年值及140→141年的真实跳变均保存。

九条模式曲线均为实线，配色与Figure1一致；无组均值或多模式均值。细竖点线仅标明CO2在第140年之后反转。白色背景无网格，无顶部标题。
