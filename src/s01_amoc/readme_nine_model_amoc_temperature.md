# n52–n53：九模式AMOC—温度路径

## 数据与实际维度

标准tas均为`tas(time,lat,lon)`，单位K，使用同AMOC成员：Can r1i1p2f1；CNRM/MIROC/UK r1i1p1f2；其他r1i1p1f1。原生网格分别为ACCESS145×192、Can64×128、CAS128×256、CESM192×288、CNRM128×256、GFDL180×288、MIROC64×128、Nor96×144、UK144×192。CESM纬界为`lat_bnds(lat,nbnd)`，其他带纬界模型为`lat_bnds(lat,bnds)`；CNRM无纬界，用已核验Gaussian节点求积。经度均匀覆盖全球。

复用n24已审计的CESM/CNRM/GFDL/Nor全球月均值，保持其月日数加权年均；其余模型从原始tas读取。输出月表按model/phase/calendar_year/month显式索引，年表按model/simulation_year索引。AMOC直接读取既有九模式40°N附近大西洋—北冰洋、500m以下最大值的原始强迫列；不读取或减去piControl参考列。来源CSV虽含piControl列，当前产品没有使用它们。

TAS原始升碳/CDR日历起点：ACCESS101/241、Can1850/1991、CAS200/340、CESM1/1、CNRM1850/1990、GFDL1/141、MIROC1850/1989、Nor1/141、UK1850/1990。各阶段分别相对编号1–140、141–280，不用文件列表位置代替日历。不采用温盐任务GFDL源6年起的特殊映射。

## 显示与解释

每模式温度相对自身原始初始1–10年，AMOC保持Sv绝对强度；不是观测工业革命前基准。11年居中滑动均值按两个CO2阶段分别计算，端点至少6个值；缺测中心维持NaN，不跨强迫转折平滑。线严格按时间连接，不按温度排序、不强制闭环。蓝实线为CO2上升、红虚线为CO2降低，不预设降碳即立刻降温。淡线是逐年变化，不是不确定区间。

图件为九模式探索性总览，不更改既有八模式分组、四模式n25主图或温度原始计算。用户明确授权CAS先使用现有代理画图；保留脚注，不把CAS代理宣称为正式2m气温。当前为八条完整标准2m气温路径加一条CAS代理路径。路径不重合可以描述暂态记忆，但不是永久不可逆或跨临界点的证据。

计算在`src/s01_amoc/n52_nine_model_amoc_temperature.py`，正式计算结果在`output/s01_amoc/n52_nine_model_amoc_temperature/`；绘图脚本`plot/s01_amoc/n53_nine_model_amoc_temperature.py`仅读该目录；图在`figure/s01_amoc/n53_nine_model_amoc_temperature/`。独立QC核对来源、月/年权重、原AMOC、CAS代理、UK缺口、平滑、图中数据、字体和渲染。最终物理排版宽度仍待投稿版面确定，不声称Nature/GRL合规。
