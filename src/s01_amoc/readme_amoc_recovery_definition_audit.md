# n22：九模式AMOC恢复判据与路径分型审查

## 本次范围和结论层次

用户要求以之前的九模式AMOC序列，包括CAS，审查恢复百分比、绝对强度差以及两/三类滞回路径是否有数据依据。本次只新增诊断和候选定义，不改n20八模式图、n21概念图、已有初始层结分组表或四模式大气复合结果。

推荐区分两个层次：

1. **主要端点分组：两类**。候选以末期达到初始强度80%作为“基本恢复／末期未达到恢复阈值”的操作性划分。不要称为“完全恢复／永久不可逆”。
2. **路径形态描述：可有三类**。在基本恢复者内部，再用路径分离量区分弱滞回与明显滞回；另保留末期未恢复。当前样本支持这个描述性2/3/4分型，但不是三个独立物理机制或临界态的证明。

推荐不按单一90%或95%端点门槛硬造“完全/部分/不恢复”三组：Nor可能成为唯一中间成员，且结果受末期窗口影响。若后续不用CAS，弱滞回恢复子类只有ACCESS一个模式，更不宜把三类作为具有充分独立模式重复的组间显著性复合。

## 数据口径与维度

来源：`output/amoc_s01_n01/l_40/CMIP6_AMOC_9models_annual_series.csv` 的 `Forced AMOC strength (Sv)`，不读取旧订正异常列、不改原值、不做piControl漂移订正、不读取原始NetCDF。AMOC为最近40°N纬度、500 m及以下Atlantic–Arctic流函数最大值，不是固定500 m流量。实际成员、纬度保存于本次端点表。

源CSV维度：`Model × Simulation year`；透视后：`Simulation year × Model`。正式分析仅合并第1–280年；CO₂峰值在第140年。九模式包括ACCESS、CanESM5、CAS、GFDL、Nor、UKESM、MIROC、CNRM、CESM2。初始1–10年是强迫试验早期参考窗口，不是独立平衡态piControl。

## 1. 不要混用两个“恢复百分比”

定义 `M0 = mean(M[1:10])`，`ML = mean(M[271:280])`，`Mmin`为1–280年11年居中滑动平均的最低值。

- `R = ML / M0`：末期达到初始强度的比例。建议用作主要恢复判据，避免跨模式初始强度不同带来的绝对Sv阈值偏差。
- `F = (ML - Mmin) / (M0 - Mmin)`：最大损失被补回的比例。可作补充，但依赖平滑与被选最低值，最低点的选择会影响F，不能把它当作无偏的强迫响应估计。
- `D = ML - M0`：绝对残余强度差，单位Sv。始终同时报告。

二者均允许超过100%，不能截断后隐藏超调。以Nor为例：R为88.1%，F为84.3%；“恢复到初始的88%”与“补回损失的84%”不是同一句话。

## 2. 80%门槛为何是可用候选，而不是必须选的真值

末期十年R在UKESM的64.0%与Nor的88.1%之间有当前样本空档；0.70、0.75、0.80、0.85均产生相同5/4分组。因此不能声称80%由数据唯一估计，更不能将这一样本间隙称为自然临界点。

将末期改为最后20或30年，并分别采用固定最初十年参考或同长度初期参考，70%、75%、80%分组均保持一致。85%在较宽窗口下会将Nor划出；90%在标准末期十年窗口下已经将Nor划出。故80%是具有窗口稳定性的“基本恢复”候选，而非近乎完全恢复。

候选基本恢复：ACCESS、CanESM5、CAS、GFDL、Nor。候选末期未恢复：UKESM、MIROC、CNRM、CESM2。这里是纯AMOC端点分类；此前高初始层结筛选是另一维度，不因此消失或自动被替换。

| --- | ---: | ---: | ---: |
| ACCESS | 100.5 | 103.8 | 103.8 |
| CanESM5 | 102.0 | 97.5 | 91.9 |
| CAS | 101.9 | 99.9 | 100.1 |
| GFDL | 98.0 | 90.3 | 86.9 |

上表固定最初十年参考。另保存了初末同长度的敏感性结果。不同窗口对应不同CO₂水平及趋势段，因此点的差异不是置信区间，不是同一平衡态的估计误差。

绝对阈值也需人为选择。标准十年末期，以距初始不超过2 Sv为准会排除Nor，不超过3–5 Sv则纳入Nor。模式初始强度约13–22 Sv，相同3 Sv对应约14–23%的相对差，因此建议以R为主、D为补充，而不是用绝对Sv作为唯一门槛。绝对容限还应区分“只要求不低于初始减容限”与“在初始上下容限内”，以免忽略超调。

若正文关注“接近原始状态”，可另报告±10%或±5%的对称近回归带，而不是将80%称为完全恢复；更严格的统计等效需要预先说明容许差异，并依赖适当的变率与自相关估计。不显著不同不能自动证明相等。本次没有做这种等效检验。

## 3. 三类路径有何数据依据

`A = integral(|Mdown(C) - Mup(C)| dC)`；`A* = A / [M0 * (Cmax_common - Cmin_common)]`。这是按线性CO₂浓度积分的平均相对路径差，不是按年份简单平均。共同浓度域为287.547…1146.515147 ppm，升高第k年与合并第280−k年配对，k=1…140；没有补造升高第0年AMOC。第140年共享峰值，交叉段用两三角形精确面积求和。

当前11年平滑下，ACCESS和CAS的A*为0.0450与0.0650；另外三个基本恢复者Can、GFDL、Nor为0.1554、0.1607、0.2168。因此在端点判据R≥0.8之上，可探索如下两层路径描述：

| 路径名称 | 候选操作定义 | 当前模式 |
| --- | --- | --- |
| Weak-hysteresis recovery | R≥0.8 且 A*<0.10 | ACCESS、CAS |
| Pronounced-hysteresis recovery | R≥0.8 且 A*≥0.10 | CanESM5、GFDL、Nor |
| Incomplete recovery | R<0.8，不再按面积拆分 | UKESM、MIROC、CNRM、CESM2 |

0.10意为平均分支差约为初始强度的10%，不是恢复到初始的10%。它是本文可讨论的描述性容限，不是文献给出的物理阈值。候选表明确标注尚未采纳，不修改现有membership。

把A*门槛改成0.08、0.10、0.12、0.15，并使用不平滑、5、11、21年平滑，所有组合均保持同一2/3/4模式分型。九模式当前数据支持这个分离；但由于两道阈值是在观察样本后探索的，必须披露探索性质，不能据此声称发现三个自然簇，更不能调整它来优化下游温度、海冰或降水的显著性。CAS被排除时第一类仅一个模式。

建议把第二类名称从旧概念图的Delayed recovery改为Pronounced-hysteresis recovery（若用户决定采用三型）；因为这里的定量界定依据是路径面积，不是某个严格恢复时长。旧n21示意图本次尚未更名或修改。

## 4. 时间序列不能忽略的两个问题

1. **最低点滞后不等于恢复时间。** 11年平滑最低点相对CO₂峰值的滞后分别为ACCESS −1、CAS 11、Can 31、GFDL 26、Nor 18、UK 34、MIROC 48、CNRM 32、CESM2 61年。CAS在不同平滑下为8–13年，不能只凭10年界限判定它是否滞后；GFDL最低年份也对平滑有变化。路径面积的分离比这个精确时间界限更稳定。
2. **末期未恢复不等于停止恢复。** CESM2最后十年较前一十年增长2.85 Sv，最后20年OLS趋势为+2.87 Sv/十年；它仍明显回升，但在第280年尚未达到80%参考。Nor末期20年趋势为+2.32 Sv/十年，GFDL为+2.51 Sv/十年，均不能当作已经到达稳态。这些斜率只是描述性估计，未检验显著性。

保存的“持续越阈年份”定义为最低点之后，首个完整十年滑动均值越阈且之后每个完整十年均值均保持越阈的窗口结束年。80%阈值时：CAS 190、ACCESS 226、Can 257、GFDL 262、Nor 274；其余到280年未达到，属于右删失，不能赋予无限恢复时间。不同定义（平滑首次交叉、连续年均越阈等）会改变年份，不能混用。
