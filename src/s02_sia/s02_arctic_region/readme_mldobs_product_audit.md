# n060：mldobs观测衍生混合层产品核查

## 目的与范围

在绘制八模式三组混合层时间序列并叠加观测参照前，先核查用户指定的`F:/sea/mldobs/mld_obs/`。本轮不覆盖原始MAT、不修改现有模式时间序列，不选择性把负深度置零，也不重新应用附件时间窗口表。分组继续沿用n059的2/2/4固定成员。

## 文件与实际维度

实际有两种方法目录：`ELG`和`second_derivative`。每种方法均含：

| 目录 | 文件数 | 字段含义 |
| --- | ---: | --- |
| clim | 12 | 2005–2025年月气候态，一月一个文件 |
| depth100m | 792 | anchor_depth_m=100的月异常产品 |
| depth300m | 792 | anchor_depth_m=300的月异常产品 |

用户确认逐月时间为1960年1月至2025年12月，含首尾792个月。逐个MAT的`year/month`用于核对；文件名0241–1032为内部时间索引，不解释为年份或缺少本次序列的前240个月。气候态24个文件，异常3168个文件，共3192个MAT。

MAT文件是MATLAB5格式。`mld_obs`和`MLD`是相同数值的别名，**不是两个可相加的分量**。两者实际维序均为`longitude,latitude`，形状`(360,180)`；`longitude`原形状`(360,1)`，范围0.5–359.5°E；`latitude`原形状`(1,180)`，范围−89.5–89.5°N。用`loadmat(...,squeeze_me=True)`后坐标为一维，场不转置。单位为m，缺测为NaN；异常0和负异常均有效。

导出NPZ中`reconstructed_mld_m`维序为`product,year,longitude,latitude`，形状`(4,66,360,180)`，year为1960–2025的三月；product顺序为ELG100m、ELG300m、second_derivative100m、second_derivative300m。它是待审查的气候态基准重构值，不是已认可的原始绝对MLD。

## 文件元数据给出的上游处理

以下来自MAT内置元数据，**不是本轮重新执行或已逐行核验的上游算法**：

1. 方法字段为`MLD_ELG`或`MLD_second_derivative`，版本`V6_deseason_20261015`。文件夹没有提供原始温盐剖面、ELG具体公式、QC阈值或上游No04源代码。
2. 气候态：对QC保留的单剖面结果，汇集2005–2025年同一日历月，计算均值，再做V4 WOA-style Barnes空间映射；`first_guess_source_years=[1960,2025]`，影响半径为892/669/446km。`external_WOA_MLD_used=0`说明没有使用外部WOA混合层数据，不能把“WOA-style”写成“WOA观测MLD”。保留first_guess_only、profile_count、valid_year_count等支持信息。
3. 异常：先按月、按格点对原始剖面MLD取中位数，减去同月份映射气候态，进行No04时间窗口nanmedian，然后减去该输出在2005–2025年对应日历月的平均值，即额外做逐月残差中心化。
4. `depth100m/depth300m`通过字段`anchor_depth_m`表明其处理深度参数为100/300m；**不是需要额外加100/300m，不是只显示上100/300m，也不是该产品最大允许MLD**。该参数如何精确控制No04窗口，仍需上游代码确认。

令逐月格点中位数为H(t)，同月份气候态为C(m)，去季节后的时间窗口中位数为S(t)，残差月均值为B(m)，则文件说明对应：

```text
S(t) = temporal_nanmedian[H(s) − C(month(s)), s属于上游时间窗口]
B(m) = mean[S(t), 2005–2025年且month(t)=m]
A(t) = S(t) − B(month(t))                  # depth目录的mld_obs
R(t) = C(month(t)) + A(t)                 # 本次重构的气候态基准值
```

必须使用**同方法、同月份、相同网格**的C。100m和300m是两套平行方案，不能相加；两种方法不能交叉拼接。由于逐月气候态、窗口中位数和残差中心化并存，R不等于原始H，也不能声称恢复了未平滑的绝对深度。MAT明确标记`field_not_original_absolute_MLD=1`、`anomaly_requires_residual_normalization=1`及`anomaly_not_smoothed_absolute_minus_this_climatology=1`。

## 本轮实际执行的处理

脚本为顶层顺序分块，无自编函数；不读原始温盐、不重算模式MLD。

1. 核查24个月气候态文件及3168个月异常文件的年月、单位、维序、坐标、基准期、方法参数和别名一致性，保存每个月文件SHA256。
2. 逐格点计算`R=C+A`，不填NaN，不把负异常当作无效，不把负R截为零。统计全球有限值和负重构值的格点—月份计数、最小最大值。
3. 独立核查2005–2025年逐日历月A均值是否接近零；输出最大残余及有完整21年支持的格点数。
4. 使用`mld_coast_regions_20261012.geojson`中现有Labrador–Irminger与Nordic手绘海岸多边形，选择1°格点中心，以cos(latitude)加权；只对当年三月有效R格点求均值，同时保存覆盖面积比例和负值面积比例。没有按MLD>100/300/500m筛选区域。
5. 区域气候态支持为该月气候态有限的多边形内格点；区域覆盖率是当年有效R面积/该支持面积。逐年格点支持可能变化，因此不能认为逐年区域A均值严格为零，也不能把覆盖变化误认成MLD变化。另存当年有效格点上的C均值，以检查`区域R=同支持区域C+同支持区域A`。
6. 在两套anchor均有效的**共同格点**上比较300m−100m，避免覆盖差异被混入方案差异。

## 本次核查发现

1. 全球所有月的有限重构格点—月份中，ELG100m为4,940,138个、负值137,156个（约2.78%）；ELG300m为5,264,281个、负值147,195个（约2.80%）；二阶导数100m为5,601,836个、负值111,640个（约1.99%）；二阶导数300m为5,945,402个、负值119,255个（约2.01%）。这不是面积加权比例，也不是独立观测样本比例。
2. 2005–2025逐格点逐日历月异常均值最大绝对残余：ELG约1.5×10^-5 m、二阶导数约6.1×10^-5 m，与浮点舍入相符，支持文件所述额外逐月中心化确已发生；不用于证明全部上游实现正确。
3. 现代2005–2025年3月，两个区域100m与300m方案的区域重构、覆盖率和负值统计完全一致，共同格点差异也为零。这是本期、本区域结果，不推断两套产品全球全时段相同。
4. 同期逐年有效格点区域均值的年平均与年际SD：Labrador–Irminger ELG157.50±20.86m、二阶导数118.32±15.73m；Nordic ELG124.77±14.94m、二阶导数105.32±9.51m。**这些是带覆盖限制、仍含负格点的诊断数值，不是推荐的正式观测区域基准或置信区间。**
5. 现代三月平均覆盖率：Labrador–Irminger ELG45.17%、二阶导数44.99%；Nordic ELG39.10%、二阶导数38.74%。分母为多边形内气候态有限面积，并非全球海洋面积。负重构格点的年平均面积比例依次为1.79%、1.61%、2.62%、2.48%。早期Labrador–Irminger最小覆盖只有约5–7%，不能把整段区域均值无条件当作覆盖一致的气候序列。
6. 直接完整区域3月气候态不同于逐年有效格点均值：Labrador–Irminger ELG165.78m、二阶导数129.04m；Nordic ELG124.86m、二阶导数106.13m。两种统计支持与权重不同，不能互换。

## 解释边界与后续画图

- **负异常合理，负绝对深度不具有物理意义**。出现负R时，不能无说明地置零或删除；需要检查上游残差中心化、空间气候态与原始局地月统计的匹配。负R不自动证明原始剖面算法错误，它首先说明“C+A等于原始物理绝对MLD”的解释不成立。
- 本产品ELG/二阶导数法与现有模式“相对10m参考sigma0增加0.03kg/m³的首次向下crossing”定义不同。不能把差异全部归因于模式误差；可先当方法依赖的观测衍生参照，若要严格技能比较需统一定义或做方法敏感性。
- 本产品气候态为2005–2025；此前N²观测为2005–2024。若后续另取2005–2024年MLD平均，不可再称为文件原始21年基准。first_guess_only区域也不能称为该月都有直接观测支持。
- 观测自然历1960–2025与理想化CO₂实验第1–280年不是同一时间轴。后续可用现代观测三月均值/年际范围作水平参照，或独立观测时间子图；不应直接把1960年当作实验第1年。
- 用户附件时间窗表仅作为上游处理背景。表内±数字的单位、区域边界和此V6产品的确切实现，需No04源代码或正式说明确认；不凭截图再做一遍平滑，不把年际SD当作独立样本置信区间。
