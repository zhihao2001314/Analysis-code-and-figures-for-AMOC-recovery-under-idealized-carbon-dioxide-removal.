UK维持排除，ACCESS不加入。恢复GFDL/Nor，未恢复CESM/CNRM。严格沿用CDR131–140减上升1–10，DJF各30个月按天数加权。
运行顺序：n22_pairwise_jet_budget.py → check_n22_pairwise_qc.py → plot/n23_pairwise_jet_budget.py。

## 来源、实际维度与支持

气候变化来自n01，(model,lat,lon)，固定四成员共同有效格点比较配对。地图保留原高斯网格，不新增重网格或平滑。
850hPa两期风来自p02_ua/n12，(model,period,lat,lon)，转经度坐标后不改变数值。地区剖面为(sector,model,period,lat)。
水汽变化来自n14的1度网格(model,lat,lon)，与粗网格气候图分开，不插值混合。
四个pair为CESM/GFDL、CESM/Nor、CNRM/GFDL、CNRM/Nor，先每模式late−early再作差。四pair平均等于组差，配对并不独立，不能用n=4当独立样本显著性。

## 急流诊断定义与解释边界

保留原平方风质心，另算峰值风速和平方风RMS纬度宽度（不是FWHM）。西区60W≤lon<0，东区0≤lon≤60E；整区60W–60E。
局地候选为逐经度季节气候态u850在30–70N内的离散最大值，不是逐日涡旋驱动急流追踪或经验证连续轴。
不填补、不做亚网格峰值拟合，不跨越不可靠经度强行连接。图上用散点，灰叉保留被标记的候选。
标记：纬度有效率<80%；最大值在搜索边界；相邻纬度缺测；最大风<3m/s；相距≥5度的另一个正局地峰与主峰风速差<2m/s。
敏感性独立测试最低风速2/3/4m/s和双峰间隔1/2/3m/s；不根据移动方向优化阈值。
仅在early、late均通过同一判据的经度配对统计。各模式可用经度不同，不能将各自子集平均直接当统一急流指数比较。
基础判据：全区43个经度，两期可用数GFDL21、Nor35、CESM29、CNRM18；CNRM东区仅1个经度，不可外推整条东部轴。
GFDL全区候选位移平均−1.33度、中位数0；Nor−0.40度、中位数0；CESM−1.35度、中位数0；CNRM+2.64度、中位数+2.79度。
这些是候选峰值位置变化，不替代原质心，更不代表统计显著的实际路径平移。
九套判据下全区配对均位移范围：GFDL−1.40至−0.93；Nor固定−0.40；CESM−1.51至−1.27；CNRM+2.26至+3.16度。

## 主要结果

海洋SPNA45–65N/60W–0：冷却、降水减少、蒸发减少、P−E增加、850hPa梯度增强的跨组四配对均同号。
组差分别tas−3.709K，P−0.637、E−1.093、P−E+0.456mm/day，梯度+1.065K/1000km；海冰浓度仅3/4配对同号，一个配对为−0.0028个百分点接近零。
欧洲陆地35–65N/10W–30E：冷却和降水减少四配对同号；降水组差−0.308mm/day。P−E仅3/4同号。
LI沿岸海冰增加和冷却四配对同号，但降水/蒸发3/4，850hPa风仅2/4同号。
GFDL整区峰值风增强0.657m/s、宽度收缩0.453度；Nor峰值减弱0.714m/s、宽度增加0.153度。
CESM西区质心−0.919度而东区+1.305度；整区仅+0.295度。不能写统一北移；CNRM西区与东区质心均北移，但局地候选东区多峰较多。

## 收支不可混用区域

收支框50–65N/60W–0与45–60N/10W–20E均包含陆海，不等于上面海洋/陆地区域。
组差副极地框P−0.663、E−0.967、月均流MFC−0.094、−storage+0.003、残差+0.394mm/day。
欧洲框P−0.267、E−0.210、MFC−0.175、−storage−0.003、残差+0.121mm/day。
残差空间RMS与P−E空间RMS之比分别0.834、1.956，不是“百分之多少降水未解释”。恒等式成立不等于物理收支已闭合。
