## 地图和两种位置的含义

填色为later−initial；第三行是ΔIncomplete−ΔSubstantial。前两行叠加各自初末雨带格点，蓝色空心圆为Initial，洋红叉号为Later。每个经度画一个最大格点，不连接成光滑线、不中间插出位移；每时期全部180经度。若完全相等的多个最大值，取最南格点，并记录并列数；±20°边界最大值单独记录。地图格点是公共2°网格，不是原模式原生格点。

单最大值会在双雨带、季风降水之间跳换，不能把每个跳动都理解为整条ITCZ平移。第三行差值场没有单一early/later气候态，不给它伪造初末雨带。两组定位应看前两行。
