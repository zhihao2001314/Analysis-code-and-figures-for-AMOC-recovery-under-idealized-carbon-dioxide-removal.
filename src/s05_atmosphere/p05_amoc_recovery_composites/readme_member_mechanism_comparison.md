# 四成员机制对照：先展示差异，再解释组均

## 运行与维度

依次运行计算 n16_member_mechanism_comparison.py、绘图 n17_member_mechanism_comparison.py。
仅整理已验收的 output，不重读原始场，不改变时间窗口或急流定义。
context 输入来自 n09 的 tas/u850/gradient850 与 n01 的 siconc，实际维序均为 (model,lat,lon)。
moisture 输入来自 n14，实际维序均为 (model,lat,lon)，保留既有1度网格。
组均替换 model 为 group，组内差替换为 pair；两种网格分开保存，不新增插值。
所有变化均为CDR第131–140年减上升第1–10年，DJF各30个日历月、天数加权。
组均 skipna=False，缺少任一成员即缺测，不在不同格点改变成员数量。
区域表来自已有海洋/LI掩膜并对四模式共同有效格点加权；场型相关另用30–70N、60W–20E，包含陆海。

## 主要证据

当前组别为 AMOC端点恢复分组，不是所有深对流指标完全恢复的分组。
GFDL AMOC98.0%，LI平均MLD210.4%、深混合面积520.6%；Nor分别88.1%、72.9%、98.8%。
MLD比值继承原始诊断：GFDL early仅5个有效年，不能当作完整10年基线的同等精度估计。
Nor Nordic平均MLD为138.8%，显示区域间也不一致。

副极地海洋45–65N、60W–0：GFDL海冰浓度−0.408个百分点、tas+1.318K；Nor海冰+3.699个百分点、tas−1.049K。
同区850hPa梯度变化分别+0.140和+0.669K/1000km，冷却和梯度响应也不完全相同。
四成员海冰/温度图显示未恢复组在格陵兰南侧有更强海冰增多和冷却，但恢复组均值掩盖GFDL/Nor的暖冷反差。
恢复组水汽输送场型相关0.099、动力项−0.038、P−E0.108，不能把弱组均视为两个成员都没有响应。
未恢复组P−E相关0.395，但降水仅0.103、动力项0.090，同样不能宣称其全部机制高度一致。

急流沿用NA60W–60E区域850hPa平方风加权纬度，不根据新机制图重新定义。
GFDL −0.329度、Nor −0.702度、CESM +0.295度、CNRM +2.879度。
同组方向在这个指标下相同，但幅度不同；未恢复组均北移明显受CNRM较大变化影响。
地图右列线为同层纬向风变化，不是急流轴；温度梯度只提供同层空间对应证据，不等同于证明急流位移机制。

水文图保留P、E、P−E三项，E向上为正。P−E增加不能解释为降水增加。
水汽输送分解及残差继续使用n15三张图；副极地区域组差残差明显，不能据此完成定量归因。
支持假说为区域海冰、冷却、蒸发及环流响应相联系，但海冰与冷却也可能受共同海洋热输送控制；两成员组不能独立识别海冰因果效应。

## 图件和核验

n17输出members_context、groups_context、members_moisture、groups_moisture，均有PNG/PDF/SVG。
同一列固定色标，超出范围用色标端部三角表示；不平滑、不填补，灰色为无效/不适用格点。
图形技能用于保持成员展示、统一尺度、显式缺测和解释限制；未对数据做视觉增强。
四张PNG逐张目视检查标题、图例、色标、标签和缺测显示。
n16复核等权组差恒等式；原有正式output/figure未覆盖，未提交或推送Git。
